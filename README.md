# Harvest-IQ

**"Smart Decisions. Better Harvests"**

Harvest-IQ is a web application designed to help farmers make informed decisions based on soil health, and plant disease data.

## Features

### 1. Crop Recommendation
- **Description**: The system recommends crops based on environmental factors like soil nutrients and weather.
- **Input**: Nitrogen, Phosphorus, Potassium, Temperature, Humidity, pH, Rainfall.
- **Output**: The most suitable crop for the given conditions.

### 2. Image-based Disease Classification
- **Description**: Using deep learning, the system classifies plant diseases from uploaded images and provides treatment recommendations.
- **Input**: Plant image.
- **Output**: Disease prediction and treatment suggestions.

### 3. Fertilizer Recommendation
- **Description**: Suggests fertilizers based on soil's nitrogen, phosphorus, potassium, pH, and moisture.
- **Input**: Nitrogen (N), Phosphorus (P), Potassium (K), pH, Moisture.
- **Output**: Recommended fertilizers.
